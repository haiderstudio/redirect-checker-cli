# Security Policy

This tool runs locally, collects no data, sends nothing anywhere except the HTTP requests to the URLs you name, and needs no API key or secret. It only reads the URLs you give it, and it never changes anything — on your machine or on any site. It writes nothing except the report on standard output (and usage errors on standard error).

If you find a case where the tool changes a file or a site, or reports a chain that does not match the real hops, please open an issue describing the exact commands and input. Do not include any real secret in the report.
